## Project Introduction 

- This project serves two purposes for me: 
    - The first and most important one is to submit work for the Web Development 1 module as part of the Certificate in Computer Science. 
    - The second is to apply what I have learned independently while completing [The Odin Project's Foundation course CSS and HTML sections](https://www.theodinproject.com/paths/foundations/courses/foundations)

#### What the project does:
  The project is an 8 page webiste on the Brontë sisters examining their family, works, personal letters, personalities, and the major events in their lives. It has hero images from scenes from their books and places in haworth that were meaningful to them. Below the heros are content sections about them as people. The site is meant to have a coherent feel in terms of colour scheme and layout and use the techniques from week 1-4 of our Web Dev 1 course effectively (as well as some others I got from the odin project). When I was building this page I was thinking "This is something I want myself and others to be able to look at in six months, twelve months, two years time, and say — Yeah, thats a clean looking website"

#### Why the project is useful:
  
  - The project is useful both to the viewer and me for different reasons.
    - For the general audience it is full of information laid out in a coherent way that is informative about the Brontë sisters. If someone has an interest in literature they could use it as a starting point to learn about the Brontes' and their literary legacy.
    - For me it was my first chance to build a complete website and put into practice everything I have learned so far in the first four weeks of the first web development module I have ever taken.
#### How users can get started with the project
- The easiest way for a user to get started with this project is:
    - Navigate to the pages directory to view the html files
    - Navigate to the assets/css directory to view the css files
